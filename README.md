## 📁 Featured project

### [ai-dev](https://github.com/germanmunozs/ai-dev)

A Go CLI that guides a Spec-Driven Development workflow with coding agents (Claude Code and Codex CLI), keeping the human in charge of every decision.

- **What it does:** checks the environment, evaluates each feature's lifecycle state, recommends the next SDD step and the agent for each role, runs agents without raising their permissions, and records explicit human approvals. It includes a keyboard-driven terminal cockpit (`ai-dev tui`).
- **How it is built:** each of its 12 features went through specification, plan, tasks, implementation and independent review with [Spec Kit](https://github.com/github/spec-kit).
- **Quality and supply chain:** CI on macOS and Linux with race detection, fuzzing, govulncheck and staticcheck; actions pinned by SHA; reproducible release archives with checksums and signed SLSA provenance.
- **Stack:** Go, GitHub Actions, Bubble Tea.
